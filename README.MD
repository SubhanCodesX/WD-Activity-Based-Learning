## Project Overview

This repository contains three website projects developed as part of the Web Development Activity-Based Learning assignment. The websites are built using HTML and CSS to practice webpage structure, styling, navigation, and layout design.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

## Projects Included

### 1. GameZone — Gaming and Esports Community Website

**Case Study 23**

A gaming community website featuring a dark theme, navigation menu, hero section, gaming statistics, and sections for games, tournaments, and community activities.

**Key features:**
- Gaming-themed user interface
- Navigation links
- Hero section with a call-to-action button
- Gaming community statistics

### 2. CampusDesk — Student Academic Dashboard

**Case Study 4**

A student dashboard that organizes academic information into cards, assignment lists, and a daily timetable.

**Key features:**
- Sidebar navigation
- Pending assignment summary
- Completed tasks and upcoming tests
- Assignment table with due dates and statuses
- Daily class timetable

### 3. LearnEasy — Online Learning Platform

**Case Study 3**

An online learning website designed to introduce courses and encourage beginner-friendly, self-paced learning.

**Key features:**
- Navigation menu
- Hero section
- Course exploration button
- Learning benefits section
- Clean, warm color scheme

## How to Run the Websites

1. Download or clone this repository.
2. Open the project folder.
3. Open the folder of the website you want to view.
4. Double-click `index.html`.
5. The webpage will open in your default browser.

No additional installation is required to view these static websites.
